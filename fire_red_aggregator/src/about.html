Description

A real-time Pokémon FireRed/LeafGreen Nuzlocke companion. The tracker reads game memory via RetroArch's UDP interface and streams party state, encounters, deaths, badges, and events to this aggregator over TCP. The aggregator serves live WebSocket overlays suitable for OBS Browser Sources, a web-based DB viewer, and a REST API for run data.

Themes

Most overlay pages accept a ?theme= query parameter. Append it to any overlay URL:

?theme=dark ?theme=light ?theme=minimal

dark is the default — semi-transparent dark panels, suitable for OBS chroma-key or overlay on top of gameplay footage.
light — light-grey panels on a white-ish background, better for screen-share setups.
minimal — same as dark but with reduced shadow and blur for lower-overhead rendering.
