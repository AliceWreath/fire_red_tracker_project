Description

A real-time Pokémon FireRed / LeafGreen Nuzlocke companion. The tracker binary reads game memory via RetroArch's UDP network-commands interface and streams party state, encounters, deaths, badges, and events to the aggregator over TCP. The aggregator stores everything in PostgreSQL and serves live WebSocket overlays, a full REST API, and this web UI.

Both binaries ship with an interactive terminal config editor (--config-editor-cli) and a graphical egui editor (--config-editor). The aggregator also supports direct mode, where it polls RetroArch itself — no tracker binary needed — and exposes a /join page for players to connect on demand.

Features

Tracking & Runs

  • Real-time party, encounter, death, badge, and game-clear detection
  • Per-run PostgreSQL storage with full event log and timeline
  • Multi-player support — each connected tracker gets its own slot
  • Direct-mode multi-connection — one aggregator, multiple RetroArch hosts
  • Nuzlocke rule enforcement: dupes clause (off / per-player / shared), randomizer mode
  • Soul Link partner pairing with manual override
  • Run rules, goals, catch attempts, and area-visit time tracking
  • Trainer battle log, difficulty score, luck analysis
  • Run comparison, HP closest-call tracking, catch rate calculator
  • Auto JSON backup on game clear; CSV and JSON export; Pokepaste export
  • Run import / resume; injection undo

Overlays & OBS

  • Live party, routes, caught, dead, box, HP bars, badges, next-gym, money, playtime, goals, type coverage, move usage, encounter count, vs-leader, encounter table overlays
  • Toast alerts for deaths, shinies, badges, zone entry
  • OBS WebSocket integration — replay-buffer clips and scene switches on game events
  • Overlay themes: ?theme=dark / light / minimal
  • Per-user OBS config with thread-local isolation

User Accounts & Access Control

  • Full login wall with bcrypt password hashing and session tokens
  • Per-endpoint access control — all data scoped to the authenticated caller
  • Run invite system — invite other users to access your runs
  • Run ownership and shared-access model
  • User dashboard with stats, active runs, party preview, and pending invites
  • OBS overlay access via ?token= URL parameter (no cookie needed)

Integrations

  • Twitch IRC bot — !party, !deaths, !shinies, !status, !caught, !badges, !hp, !encounters; Channel Points EventSub
  • YouTube Live chat bot — same commands via YouTube Data API v3
  • Discord live embed — persistent pinned message updated with party/run info
  • Discord run thread — new thread per run with milestone messages
  • Discord slash commands — Application Commands via /interactions endpoint
  • Webhooks — per-event HTTP POST with template variables and optional HMAC-SHA256 signing
  • LiveSplit bridge — badge and game-clear splits via LiveSplit Server
  • Desktop notifications — notify-send on death, shiny, and wipe
  • All integrations configurable globally or per-user via /integrations

Other

  • Mobile-optimized site at /mobile with auto-detection and desktop mode toggle
  • Stream Deck support via POST /api/command/:cmd
  • Batch injection, injection presets
  • Injection undo
  • Death heat map, level curve, friendship tracker, EV efficiency overlay
  • Dex completion overlay, type chart overlay
  • Savefile import, YouTube clip trigger, ghost-run comparison
  • Session summary Markdown export

Themes

Most overlay pages accept a ?theme= query parameter:

?theme=dark ?theme=light ?theme=minimal

dark — semi-transparent dark panels, suitable for OBS chroma-key or overlay on gameplay footage (default).
light — light panels on a white background, better for screen-share setups.
minimal — dark with reduced shadow and blur for lower-overhead rendering.

OBS overlays also accept ?token=<session_token> for authentication without a cookie.
